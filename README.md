Protein 101: A Beginner's Guide for Vegetarians

An interactive, single-file HTML explainer covering why protein matters, the best vegetarian protein sources, how protein drives muscle growth and fat loss, and a bonus section on dietary fibre.

🔗 Live Demo
Once published via GitHub Pages, add your link here:

https://<your-username>.github.io/<repo-name>/
✨ Features
Why Protein Matters — six benefit cards covering muscle repair, hormones, immunity, satiety, bone/skin health, and energy.
Vegetarian Protein Sources Chart — animated bar chart comparing 14 vegetarian protein sources (grams per 100g), from soybeans and lentils to paneer, tofu, and milk.
Muscle Growth Timeline — a step-by-step walkthrough of muscle protein synthesis, with key intake stats (protein per meal, meal frequency, daily target).
Fat Loss Timeline — how protein's thermic effect, satiety impact, and muscle preservation support fat loss.
Bonus: Fibre Section — soluble vs. insoluble fibre explained briefly, plus a quick-reference source list.
Smooth UX — scroll-triggered reveal animations, animated counters, a scroll progress bar, sticky scrollspy navigation, and a responsive mobile menu.

🚀 Running Locally

No installation needed — it's a static file.

Clone or download this repo.
Open index.html directly in any modern browser.

Or serve it locally:

bash
python3 -m http.server 8000
# then visit http://localhost:8000

Push this repo to GitHub (ensure the main file is named index.html).
Go to Settings → Pages.
Under Source, select your branch (e.g. main) and folder (/root).
Save — your site will be live at https://<your-username>.github.io/<repo-name>/ within a minute or two.
